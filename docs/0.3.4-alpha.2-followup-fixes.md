## F3：转义 YAML 键名和保守完整性

- 新增共享的单行 scalar key reader，配置生成器及监听分析器共用；正确解码双引号的常用 JSON/YAML 转义与 YAML 的 x/U 十六进制形式，单引号中的反斜杠保持字面值。依据 YAML 1.2.2 的转义语义：https://yaml.org/spec/1.2.2/#57-escaped-characters 。其他不支持的转义、tag、anchor/alias、复杂 root 结构不会猜测。
