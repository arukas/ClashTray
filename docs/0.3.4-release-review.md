## 固定窗口最小化后的托盘恢复

- 根因：`TogglePanel` 只看 `_isVisible`，最小化时该值仍为 true；`ShowPanel` 使用 `SW_SHOW`，不会恢复最小化窗口。
- 修复：按窗口实际可呈现状态切换；最小化时调用 `SW_RESTORE`。固定窗口恢复保留原来的位置和用户调整的尺寸。
- 在原实现中运行新 Debug 隔离 WinUI 回归，退出码 1，`failure.log` 明确记录 `TogglePanel did not restore the minimized pinned panel.`。目录：`artifacts/0.3.4-final/ui-before`。
- 修复后专项回归通过：托盘切换和“打开面板”两个入口、恢复尺寸/位置、最小化时暂停页面呈现、正常显隐。记录：`artifacts/0.3.4-final/ui-after-restore/minimized-panel-restore.json`。
