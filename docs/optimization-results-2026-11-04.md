## 2. Runtime 恢复职责

`ConfigurationStartupRecovery` 拥有配置内容/选择的启动重放、不可变恢复结果及日志保留/清理条件。Runtime 提供受既有门禁保护的生命周期操作并提交展示状态。`ServiceCoreReconciler` 集中丢失启动响应后的限时观察和绑定元数据准入；初始化、轮询接管和未知启动结果采用同一准入规则。未知服务结果仍先保留服务清理所有权，不允许本地回退。恢复的内容→选择→核心健康确认→清理顺序保持不变。

第 2 项：完整 Release/x64 构建 0 警告、0 错误；Core 808/808、隔离 Integration 37/37、官方 Mihomo 互操作 22/22，无跳过。官方归档 SHA-256 校验通过，使用隔离子进程与回环端口，未启用 TUN。新增恢复组合用例验证内容缺失时停止核心、选择失败时保留记录，以及健康确认前禁止清理记录。
