# 设置草稿与失败恢复

启动时若设置恢复与配置切换恢复同时失败，保留两个恢复记录并显示降级原因，仍继续读取真实代理状态、恢复自有代理、查询和接管现有服务。未恢复配置选择之前，不将配置事务标记完成或按旧选择自动重启核心；服务不可用的异常分支也不得清理这份记录。已有服务绑定可用于显式 TUN 关闭，自动开启仍受恢复错误限制。

临时恢复存储故障解除后，即使已经没有 journal/关闭意图，也必须先确认设置存储可读，再清除旧失败标记；仍不可读时继续保留错误。此路径不覆盖正在编辑或配置切换中的内存设置。

SettingsEditModel 是不依赖 WinUI/服务/网络的纯编辑模型：持有已加载基线、AppSettings 草稿和独立数字输入（已提交 Value、可见原始文本、未提交状态、修改状态）。SettingsPage 只投影模型、捕获控件及焦点行为，不把特权命令交给编辑模型。

快照合并保留用户编辑，未编辑字段采用最新外部值；同字段已修改草稿胜出。保存只生成修改字段的 AppSettingsPatch，在 Runtime 操作锁内再合并到最新设置。配置 ID、System Proxy/TUN 选择与主题解锁由其他入口管理。数字输入按当前文化解析、限 64 字符，必须为有限整数及既有范围，并执行端口交叉校验。NumberBox 的可见模板文本在快照与保存前捕获；无效文本不自动回退成旧 Value，不强制移焦。

成功保存只确认提交时的草稿；期间新增编辑保留。失败保留草稿与原始数字文本。语言保留重启提示，主题即时应用沿用 Runtime 通知。SettingsPageCommands 提供可等待的设置、网络、维护、端点操作槽：重复操作不再派发、错误脱敏，在实际显示反馈时重新检查页面代际，避免已经完成但排队的 UI 续体越过导航。离开页面只抑制旧反馈，已经准入的副作用继续完成。维护请求捕获端点目标与权限；代理/TUN 开关投影确认状态。

普通设置保存及网络启用在写设置和执行副作用前原子准备 settings-recovery.json（schema 1，最多 64 KiB、单条记录、无凭据的前后设置）；显式安全关闭采用下述独立关闭意图及后置持久化规则。普通保存先落盘再更改内存。原操作失败时独立 3 秒预算按记录字段恢复旧偏好，网络/核心安全恢复拥有独立 30 秒预算；用户取消不撤销恢复。回写失败保留安全内存偏好、恢复记录、脱敏错误和原始/恢复异常。初始写、设置恢复、启动项恢复同时失败时三个异常都保留。

启动及下次设置/网络启用/配置选择、回滚、删除或启动配置恢复均使用同一设置恢复协调器。schema 1 的 Previous 与 Attempted 已足以推导字段范围：只有两者不同的字段属于待恢复操作，当前该字段必须等于其中之一，才恢复 Previous；未改变字段保留当前持久值。同字段第三值冲突保留记录并报错，无关主题/配置选择等不会触发整对象冲突。旧 schema 1 无需迁移；未知版本、超限、不可读仍保留并反馈。配置事务回滚只恢复 ActiveConfigurationId，不回写整个旧 AppSettings。

安全关闭与偏好恢复分开。显式关闭 System Proxy/TUN 在现有操作锁、代理所有权或当前服务绑定限制下先执行撤销，存储故障不能单独阻止实际关闭。仅 OS/服务确认 Off 才投影 Off；真实撤销失败或外部所有权冲突保持相应错误/未知/需要恢复状态。实际关闭成功但偏好未保存时明确报告部分成功，不能声称已保存，也不回滚为 On。启用仍先解决待恢复设置；后台协调在恢复故障时不会新启用其他机制，已确认运行的独立接管不因这个门禁自动改为关闭。

同一 SettingsRecoveryJournal 管理 settings-network-off.json 伴随记录（schema 1，最多 1 KiB，仅 SystemProxyOff/TunOff 两个关闭位，原子写与现有 ACL），用于旧 journal 不可读或冲突时保留新关闭意图；记录无启用命令和凭据。关闭前尽力写入，失败仍继续安全撤销并保留内存意图；关闭后以独立 3 秒预算尝试保存。后台、配置恢复、核心新绑定及 App 重启只合并/应用关闭位，不能清除。成功显式启用才清除对应位；另一关闭位保留。读取权限错误不是“文件不存在”。如果所有持久化通道均不可写，不能保证断电后的意图耐久性，错误明确且本次进程继续保持关闭；仍存在/不可读的待恢复记录阻止自动启用。

恢复代理/TUN 偏好先按受控字段合并，再叠加关闭意图；正常 TUN 仍以服务确认后写偏好为准。已确认状态不会因存储失败消失。完成后删除主恢复记录，关闭位保持到成功显式启用。此机制不替代 System Proxy 所有权备份、配置切换 journal 或服务 TUN 回滚。

模型/命令单元测试与 WinUI smoke 分开。2026-10-02 的隔离 WinUI smoke实际检查未保存端口/开关/文本、外部主题更新、未提交数字文本、无效文本、焦点保留、失败校验、保存落盘及重新建页；未等同于人工键盘遍历、屏幕阅读器、多 DPI 或登录启动验收。
