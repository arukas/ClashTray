# ClashTray 今日开发进度

日期：2026-09-07

## 今日完成

已按照 `AGENTS.md` 的 DEFAULT IMPLEMENTATION REQUIREMENT 完成 P0 + P1 主体开发，P2 暂不实现。

- Windows-only .NET 10 + WinUI 3 应用结构与解决方案。
- 单实例托盘应用、托盘状态图标、左键飞出面板、右键快捷菜单、固定窗口和显式退出。
- Mihomo 核心发现、配置验证、启动、停止、重启、崩溃检测与控制器重连。
- 本地 YAML/YML 配置、订阅导入、选择、刷新、重载和删除。
- Rule/Global/Direct 模式、代理组、节点切换和延迟测试。
- System Proxy 备份、所有权检测、冲突保护、WinINet 通知、恢复和卸载恢复路径。
- Windows Service + 受限命名管道，用于 Mihomo 生命周期和 TUN 操作。
- TUN 状态确认、失败处理和服务不可用状态。
- 规则、连接、Provider、流量、内存和实时日志页面。
- 日志来源/级别/搜索过滤、复制、清空、限量保留和重复行折叠。
- 开机启动、自动启动核心、HTTP/SOCKS/Mixed/Controller 端口设置。
- allow-lan、IPv6、TCP concurrent、log-level、主题和系统代理绕过列表设置。
- DNS/FakeIP 缓存清理、Geo 数据库更新和 Provider 手动刷新。
- 订阅定时刷新。
- 设置页可配置订阅刷新间隔（1–168 小时），并在运行时校验范围。
- 设置页端口输入支持整数范围校验和重复端口提示，非法输入不会直接中断保存事件。
- 对齐 Mihomo 官方控制器 API：FakeIP 清理使用 POST，规则列表兼容官方对象返回格式。
- 核心更新增加 Windows x64 PE 架构校验，归档内容不符合时不会替换现有核心。
- 进程异常退出会取消输出读取、清理旧进程，避免旧退出事件影响后续启动或重启。
- 控制器客户端支持带查询参数的 WebSocket 地址和连接，结构化日志解析兼容单条实时消息。
- 服务托管模式已接入 Mihomo logs WebSocket，包含碎片消息处理、1 MiB 消息上限、断线退避和核心停止时的连接释放。
- 连接详情贯通 Mihomo 官方 rulePayload，支持按命中规则内容搜索并在详情中显示。
- 命名管道请求增加 64 KiB 长度上限、断线恢复和响应 RequestId 校验，强化服务 IPC 边界。
- 服务路径校验改为匹配系统程序数据目录或已注册用户的 ClashTray 核心目录，运行配置只能来自受保护的 ProgramData 路径。
- 托盘图标在 Explorer 重启后只重新注册图标，不重复替换窗口过程，避免托盘回调链递归。
- 初始化配置时以设置中的活动 ID 为准，并将残留的多个活动元数据收敛为一个。
- 配置与订阅导入增加 16 MiB 有界读取、元数据路径白名单和原子文件替换，设置保存也改为原子写入。
- System Proxy 开启过程增加注册表失败回滚；所有权文件写入失败时恢复原状态并保留必要的恢复标记。
- Mihomo API 解析对异常 JSON 形状安全降级，避免非字符串成员或空日志对象让刷新任务崩溃。
- 运行设置统一校验日志级别、主题和绕过列表，避免篡改的设置值注入运行 YAML 或注册表。
- 设置文件读取遇到损坏 JSON 或非法值时回退默认设置，保存路径也执行同一套校验。
- 运行配置生成只替换顶层 Mihomo 管理字段，保留代理节点内部同名字段（例如节点端口）。
- 官方 MetaCubeX/Mihomo 下载源校验、SHA-256 校验、原子替换和回滚。
- Mihomo 控制器 JSON 响应增加 16 MiB 上限，错误响应增加 64 KiB 上限。
- 定时订阅刷新失败会进入可见失败状态并记录日志，刷新任务会继续运行；手动和定时刷新互斥。
- 核心更新归档限制为 128 MiB，只提取唯一的 `mihomo.exe` 并校验其大小，避免无界解压。
- TUN 服务只接受与当前运行核心匹配的端口和密钥，切换失败会尝试恢复原状态。
- 服务 IPC 区分连接前不可用和请求结果未知，避免响应丢失后重复启动核心。
- 连接、规则、节点和 Provider 解析增加条目上限；进程单行日志限制为 64 KiB 并继续消费超长行。
- 配置元数据 ID 增加十六进制白名单，阻断通过元数据触发的路径穿越。
- 运行配置临时文件使用唯一名称并在失败/取消后清理；设置文件增加大小上限和 IO 异常默认回退。
- 流量解析保留真实的零值总量；桌面操作失败增加提示，过渡状态禁止重复点击，删除配置增加确认。
- MSIX 打包、原始应用图标、托盘状态图标和 packaged Windows Service 配置。
- 运行时目录 ACL、DPAPI 控制器密钥和服务退出时的系统代理恢复。
