# 0.3.5 发布前验证

本版纳入 2026-10-02 的设计优化、R1/R2/R3 后续修复，以及再次审查发现的两项启动恢复缺陷修复。历史优化报告保持原样；最终实现以本版本源码为准。

- 设置与配置切换恢复同时失败时，保留恢复记录，继续读取真实代理状态和接管服务；不会提前清理 journal 或按未恢复的选择重启核心。
- 没有待恢复记录时，先确认设置存储可读，再清除过期失败状态，使后续正常设置保存和自动代理偏好恢复。
- 新增 StartupRecoveryAdmissionTests 的 9 个用例，覆盖持续冲突/写失败/不可读、服务不可用、运行绑定接管与 TUN 关闭、存储修复和仍不可读两种分支。
