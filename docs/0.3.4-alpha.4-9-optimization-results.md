## 1. 订阅下载整体期限（alpha.4）

- `ResponseHeadersRead` 原先仅由 HttpClient 的 30 秒响应头期限保护，正文读取没有独立期限。
- 改为一个 30 秒期限覆盖响应头、获取流和全部正文；缓慢持续返回正文也不会重置期限。继续保留 16 MiB 限制。期限到达返回 TimeoutException，调用者取消保持 OperationCanceledException；响应和流均释放。
- 确定性时钟回归先返回一段正文、再阻塞读取，然后显式触发期限，验证旧配置及受保护元数据不变、流释放、后续请求成功；另测调用者取消。未引入真实订阅 URL。
- Release x64 solution build：0 警告、0 错误。Core 648/648、Integration 44/44，无跳过，固定官方核心与归档均设置为必需。

## 4. 批量日志快照（alpha.7）

- 核心日志逐行只写入有界 buffer 并请求既有 250 ms 发布节流；发布或显式读取运行快照时才合并待处理日志。应用操作日志立即合并，生命周期发布不被日志节流延迟。无待处理日志时读取不产生新快照。
- 控制器日志也在读取/发布时物化快照，保留 session/generation 限制。继续保留 500 条、重复行折叠、脱敏和单调序号；清空后不会重新发布旧的待处理行。
- 回归覆盖 10,000 行突发、最新 500 条、无变化快照引用、清空、核心日志与即时应用错误日志混合。性能夹具 `--log-snapshots` 在同一实现下比较原逐行物化策略与每 250 行物化策略。
- .NET 10.0.12 x64、10,000 行、7 次样本：托管分配中位数 43,162,272 B → 2,086,960 B；耗时中位数 33.949 ms → 5.218 ms。测量包含相同有界缓冲、脱敏及状态更新，不包含 WinUI 布局或真实时间调度；不是整机/UI 性能结论。原始输出 `artifacts/alpha4-9-performance/logs.txt`。

## 5. 大列表通知、搜索与虚拟化（alpha.8）

- 连接、日志、规则搜索合并 200 ms 内输入；取消、更新输入、卸载和退出使已排队旧回调失效。筛选/排序显式切换立即应用。批量列表更新按修订号恢复滚动位置与列表内焦点，避免旧恢复回调覆盖后续投影。

## 6. 面板可见性与按页刷新（alpha.9）

- 隐藏/最小化面板跳过 WinUI 快照投影，运行时保留最新状态，托盘仍接收状态。重新打开或切页先显示最新缓存，再立即请求该页数据；进行中的刷新合并后续请求，避免快速切页丢掉最后一页。旧页失败不会在已切换页面显示。
- 本地健康、监听归属和恢复仍保留原 2 秒循环；既有控制器管线保留原 5 秒配置刷新。启动首次数据、操作后确认、订阅调度和有界日志采集仍独立执行。
- 可见页的指标及本页代理/连接列表跟随原轮询周期；其他页页头连接数、可见规则/Provider 最短 10 秒刷新。Provider 读取与规则分开，代理/设置页刷新 Provider 时不会附带读取规则列表。隐藏或非活动控制器每 30 秒补指标及连接缓存；本地/远程时钟独立，避免相互耗用期限。未注册面板的测试/其他 host 维持原策略。
- 没有请求的项目保留数据、availability、列表总数和截断摘要。继续在提交前后核验 binding/session generation，迟到旧响应不提交。显式刷新保持全部数据请求。
- 确定性回归覆盖隐藏、重开、切页、独立期限、未请求数据保留、调用者取消、请求期间绑定变化、配置持续确认。本地运行时隐藏连续三次调用原轮询读路径，仍发出三次 `/version` 和三次 `/configs`，没有非关键列表/指标请求。
- 同一 Coordinator 的五分钟模拟（150 次、每次推进 2 秒）：原策略 600 个非关键资源请求，隐藏策略 30 个（traffic/memory/connections 各 10）；这是确定性请求计数，不是整机 CPU、内存、电耗或 WinUI 帧率测量。
- Windows 可见性事件按 [Microsoft AppWindowChangedEventArgs 文档](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.windowing.appwindowchangedeventargs?view=windows-app-sdk-2.0) 接入。顺带修正已有 UI smoke 导航断言，使规则页同连接/日志一样检查独立 ListView 容器；没有声称实际执行 Windows UI smoke。
