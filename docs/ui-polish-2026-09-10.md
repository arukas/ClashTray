# UI polish — 2026-09-10

The tray panel now uses a soft neutral canvas, separate Fluent surfaces, compact navigation, consistent spacing and theme-aware accent text. Light and dark surfaces have dedicated colors; high contrast uses system window/text/highlight resources. The existing logo and system accent remain in use.

## Changes

- Node groups have distinct cards with the group name and confirmed current node on separate lines. Selected nodes carry both the native selection indicator and a check mark. Full names remain available as tooltips and accessible names.
- The dashboard is the only vertical scroll owner for proxy groups. Node ListViews no longer have a fixed 240-pixel height and explicitly disable their own horizontal/vertical scrolling.
- Collapsed groups defer node-control creation until expanded. Search matches group or member names after a short debounce, shows an explicit no-results message and preserves manual expansion state when cleared.
- Node changes retain the confirmed selection while awaiting Mihomo. Traffic-only snapshots preserve the existing node controls.
- Search and group count share one compact row. Provider refresh controls remain available below the groups.
- Shared cards, native navigation states, Fluent theme icons and empty states in Rules, Connections and Logs use the same visual language.
