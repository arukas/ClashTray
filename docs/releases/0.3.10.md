本次 **0.3.10-alpha.1** 是界面与代码质量预发布版本，集中改进紧凑 Fluent 视觉、状态表达、列表稳定性、订阅输入和重复渲染开销。服务协议保持 **3**，官方 Mihomo 保持 **v1.19.31**，MetaCubeXD 保持 **v1.273.1**。

- 统一 8px 卡片圆角、紧凑间距、页面标题和列表样式；核心与远程端点状态使用系统语义画刷，同时保留文字状态。
- 页脚版本移除冗长源码修订号；流量采样使用单调时钟，并在遥测失效或控制器代际变化时清除旧曲线。
- 指标数字使用稳定列宽，流量图提供中英文可访问摘要；导航、模式分发和主题资源完成收敛。
- Proxy 页面改用结构化数据比较，避免每次更新进行 JSON 序列化；Rules 使用带控制器代际和源序号身份的稳定类型化行。
- 避免重复应用主题，复用 Shell 图标，集中控制器能力判断，并修复 Provider 刷新结束后按钮可能误启用的问题。
- 无效订阅地址保持对话框打开并显示本地化错误，不再直接关闭；Cancel 正常退出且不会开始导入。

本轮改动按独立提交拆分。最终视觉与交互证据见[检查点](https://github.com/arukas/ClashTray/blob/v0.3.10-alpha.1/design-qa.md)。

验证结果：Release 和 Debug 全解决方案构建均为 **0 警告、0 错误**；Core **879/879**、Integration **68/68** 通过，无失败、无跳过。Integration 包含固定官方 Mihomo **22 项**和 Windows 安全能力 **7 项**。真实 WinUI 合成场景冒烟退出 **0**，覆盖双主题、Nakhimov、流量与状态、五页面、400 条连接、500 条有界日志、重复 Rules 文本及筛选、控制器代际切换，以及无效订阅对话框。发布流水线继续执行锁定还原、完整构建、官方核心、安全能力和完整测试门禁。

**预发布范围：** 本轮没有重新完成全新安装、实际升级、卸载保留／删除数据、真实系统代理恢复与所有权冲突、真实 TUN 开关及失败回滚、服务／界面重启恢复、睡眠／网络变化、Explorer 重启、多显示器／任务栏位置／DPI、OS 高对比度和物理屏幕阅读器验收。合成 UI 检查不能视为这些场景已通过，因此本次以 **alpha 预发布** 形式提供，不作为稳定版验收结论。

普通 Windows 11 / Windows 10 x64 用户请优先使用 **Full**；NoCET 继续作为旧补丁 Windows 10 的兼容变体。两种安装包都内置经过校验的官方核心和面板资源，发布页提供 SHA-256 校验清单。
