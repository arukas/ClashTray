# ClashTray 0.2.0

- 集成本地固定版本的 MetaCubeXD 控制面板，Dashboard 资源、SHA-256、MIT 许可证和来源信息随安装包提供。
- 控制器入口在 Dashboard 可用时直接打开本机 MetaCubeXD；资源缺失时可复制 loopback 控制器地址。
- 托盘 ICO 按当前 DPI 的 Windows 小图标指标加载，面板 Logo 在 40 px 点击区域内保持更清晰的可见主体。
- 继续收紧核心生命周期、系统代理恢复、配置候选验证、设置保护、IPC 超时和高频 UI 更新路径。
- Full、NoCET、Mini 均为 Windows x64 安装包，并保留完整预发布版本号、SHA-256 sidecar 和发布清单。
