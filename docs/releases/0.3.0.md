# ClashTray 0.3.0 Alpha

这是 ClashTray 0.3.0 的早期预览版本，面向愿意协助验证 Windows x64 日常使用流程的测试用户。

## 本版内容

- 完成本机运行时状态与 Mihomo controller 会话的边界拆分。
- 为配置切换加入事务日志、失败恢复和订阅内容回滚保护。
- 强化 controller 命令能力校验，避免把不支持或未授权的操作发送给核心。
- 加固 TUN 生命周期：停止或重启前必须读取并确认 TUN 已关闭；确认失败时保留核心运行并阻断后续启动。
- 增加 Windows 网络上下文读取基础能力，为后续 SSID 自动切换功能提供安全边界。
- 增加远程 Mihomo 端点的本地元数据管理、编辑、DPAPI secret 存储、逐端点自定义 CA 和 REST/WebSocket 共用的严格 TLS 策略；不提供忽略 HTTPS 证书错误。
- 增加本机状态与端点目录的统一 AppSnapshot 发布入口，防止远程目标状态覆盖本机配置、System Proxy 或 TUN 状态。
- 保留现有的托盘、核心生命周期、配置与订阅、代理模式、节点切换、系统代理、TUN、规则、连接、日志和核心更新能力。

## Alpha 限制

- 当前仅提供 Windows x64 版本。
- 这是测试版本，真实网络环境、TUN、系统代理所有权恢复、睡眠恢复、多显示器/DPI 和安装升级流程仍需要更多设备验证。
- SSID 自动切换的真实 Windows 验收，以及远程 Mihomo 的真实会话连接器、只读连接测试、目标选择后的实时快照和允许命令 UI 尚未作为完整功能交付；当前远程部分仅交付本地元数据与安全边界。
- 使用前请备份重要的 Mihomo 配置；不要在公开问题或日志中提交订阅 URL、令牌或代理凭据。

## 验证基线

- `dotnet build ClashTray.sln --configuration Debug --property:Platform=x64 --no-restore`
- `dotnet test ClashTray.sln --configuration Debug --property:Platform=x64 --no-build`
- Core tests: 229 passed
- Integration tests: 8 passed
- 本次基线未连接真实远程 Controller，也未修改测试机的 System Proxy、TUN、路由或网卡状态。
