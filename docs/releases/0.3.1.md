# ClashTray 0.3.1 alpha.4

本 alpha 在 alpha.3 网络配置重整的基础上升级固定核心并放宽 Mini 的 .NET 运行时选择：Full 与 NoCET 内置 Mihomo v1.19.31，TUN 可使用新加入的 `mips` 协议栈；Mini 接受任意已安装的 x64 .NET Runtime 10.x，并保持 Windows App Runtime 2.4+ 检查。它面向 Windows x64；发布工作流会生成 Full、NoCET 和 Mini 三种安装器。

## 本版更新

- 固定官方 Mihomo 从 v1.19.30 升级到 v1.19.31；Windows AMD64 官方 ZIP 使用发布方 SHA-256 `38b2420799d9e7cde77ec1a19c7150dd17ca77f7fb82d9f62cb8763a307eee67` 校验。
- 与 v1.19.31 正式加入的 `stack: mips` 对齐：设置、持久化、校验、重启判定与有效运行配置生成均支持 mips；“跟随配置文件”仍保留订阅/YAML 原值。
- Mini 的 App 与 Service 显式使用 `LatestMinor`，只在 .NET 主版本 10 内选择已安装的最新 minor/patch；安装器检查 `Microsoft.NETCore.App 10.x`，不再额外要求应用并不依赖的 `Microsoft.WindowsDesktop.App`，并继续要求 x64 host 与 Windows App Runtime 2.4+。
- 设置页新增“网络配置”分区，System Proxy 与 TUN 从主面板迁入该分区；托盘右键菜单仍保留两项快速操作。
- 新增 TUN 协议栈选择，支持跟随配置文件以及 system、gvisor、mixed、mips；选择显式协议栈后由 ClashTray 写入有效运行配置。
- HTTP、SOCKS5、Mixed 与 Controller 端口、系统代理绕过列表、允许局域网连接、IPv6 和 TCP 并发统一归入网络配置。
- System Proxy 与 TUN 开关作为需要本机核心运行的即时确认操作；TUN 协议栈、端口和其他需重载的设置在核心运行时执行受控重启，核心停止时保存到下次启动。
- Service IPC 请求增加 `RequestId`、协议版本和明确的 dispatch state；请求已经写入后发生取消、超时或断连时不再错误地回退启动第二个本地核心。Service 对已接受请求提供有界 TTL/容量的结果去重。
- Runtime snapshot 收口到单写入者 `RuntimeStateStore`，使用单调 revision 和条件提交；`Publish()` 只通知已提交状态，不再在发布线程中进行读改写。
- Core health、Controller binding、进程和代理恢复携带 lifecycle/process/controller/ownership generation，重启中间状态和旧健康响应不会关闭新一代 System Proxy 或把 Failed 改回 Running。
- 退出流程变为幂等 quiescing cleanup：先停止后台生产者，再由 cleanup owner 真正取得 mutation lane 后处理 TUN、System Proxy、核心、会话、日志流和发布 worker；不再在等待超时后伪装成已持锁继续清理。并发 Dispose 共用同一任务，清理错误会脱敏记录。
- 慢的 metrics、connections、rules、providers、端点连接和节点测速不再长期占用 local-device mutation lane；Endpoint session 连接提交采用单同步边界的 committed 判断，连接重试中仍可切回本地。
- operation single-flight/latest-wins 现在区分 caller cancellation 与共享副作用生命周期；被 supersede 的 waiter 收到明确的 `Superseded`，取消的 pending intent 不会遗留永远无法启动的新请求。
- Service StartCore 在“请求已派发但响应丢失”时保守保留 Service 所有权：不会回退启动第二个本地核心，会立即并持续核对状态，退出时仍会发送 StopCore。Service 请求缓存也不会因 TTL 或容量压力驱逐执行中的请求。

## 验证

- alpha.2 基线曾完成 Debug x64 构建、283 项 Core 隔离测试和 6 项 Integration 安全边界测试。
- Release x64 构建通过（0 警告、0 错误）。首次发布工作流暴露了订阅 User-Agent 测试夹具仍绑定旧核心版本；夹具改为跟随受管清单后，283 项 Core 测试与 20 项 Integration 测试通过，另有 2 项真实核心/服务测试按环境条件跳过；最终 Release 构建与测试仍由 GitHub 发布工作流执行。

## 已知限制与安全说明

- 真实 TUN：未验证（用户明确禁止操作，以避免断网）。本 alpha 没有通过测试启停、切换、恢复真实 TUN，也没有修改测试机路由、DNS、网卡或 Windows Service 状态。
- 真实安装器安装/升级/卸载、已安装 Windows Service/命名管道、System Proxy 注册表/WinINet、Explorer 重启、多显示器/DPI/高对比度和睡眠恢复仍建议由用户在安全环境中手动验收。
- Wi-Fi/SSID 自动切换、ARM64、历史流量分析和更多语言仍不在本版本范围内。
