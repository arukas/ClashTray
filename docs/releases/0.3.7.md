本次 **0.3.7** 是托盘控制核心失效的修复版本。服务协议保持 **3**，官方 Mihomo 保持 **v1.19.31**，MetaCubeXD 保持 **v1.273.1**。

- 修复核心由 `LocalSystem` Windows 服务启动后，普通用户 ClashTray 无权读取核心进程身份，导致 Web 面板正常但托盘模式切换、节点操作及健康检查被所有权保护阻止的问题。
- 服务在每次启动及重启核心后、发布就绪状态前，为安装绑定用户增加 `PROCESS_QUERY_LIMITED_INFORMATION`。沿用进程原有 ACL，只增加查询路径和创建时间所需的权限；不授予终止进程、创建线程、写内存、复制句柄或修改权限的能力。
- 保留 PID、进程路径、创建时间、监听地址、端口及进程代次校验。用户 SID 只取安装绑定信息，不通过 IPC 接收；授权失败会停止尚未发布就绪的核心。
- 核心所有权错误展示具体原因，避免日志只显示异常类型名。
- 增加拒绝访问到查询恢复、最小权限、重复授权、官方核心启动/重启后的版本查询与模式切换，以及授权失败清理的回归测试。

请使用 **Full 安装包**升级，让桌面程序和 Windows 服务同时更新，并重启核心。仅替换桌面程序不会修复旧服务启动的现有进程。NoCET 继续提供旧补丁 Windows 10 的兼容变体。

本地完整 Release/Debug 构建通过，均为 0 警告、0 错误；最终 Core **797/797**、Integration **66/66**，无失败、无跳过。Integration 包含官方核心 **22/22** 和 Windows 安全能力 **7/7**；隔离 WinUI smoke 以退出码 0 完成。一次测试端口冲突及后续重复验证已保留在验证记录中。
