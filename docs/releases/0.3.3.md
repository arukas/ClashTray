# ClashTray 0.3.3

本版本是 0.3.2 的补丁版：修复核心版本与发布页不一致的问题，并按用户决定放宽核心的哈希校验。Full 与 NoCET 内置 Mihomo v1.19.31；面向 Windows x64，发布 Full 和 NoCET 两种自包含安装器。

## 本版更新

- **升级安装时总是替换内置核心与清单**：此前安装器对 `%PROGRAMDATA%\ClashTray\core` 使用 `onlyifdoesntexist`，旧版本的核心和清单在升级后原样保留——0.3.2 发布页标注内置 Mihomo v1.19.31，但老用户升级后实际仍是旧核心。现在安装/升级总是写入随包固定的核心与配套清单，安装结果与发布页一致。
- **删除核心启动时的哈希校验**：服务启动核心前不再比对 exe 的 SHA-256 与清单记录。历史版本的应用内更新曾只替换 exe 而不同步清单，留下的不一致状态会让核心永远无法启动（"受管 Mihomo 核心校验失败"）。保留的启动检查：受管路径与重解析点信任、清单存在且来源为官方 release、PE/x64 结构完整性。
- **应用内核心更新的 SHA-256 改为可选**：下载时只有填写了 64 位十六进制校验值才会比对压缩包哈希；留空即信任官方下载链接（仍强制 HTTPS + GitHub MetaCubeX/mihomo 官方 release 路径白名单）。Settings 页输入框与按钮文案同步更新。
- **核心版本显示回退**：Mihomo 的 Go 二进制不带 Windows 文件版本信息，头部此前无法显示未运行核心的版本；现在 exe 无文件版本时回退显示受管清单记录的版本（如 v1.19.31）。

## 验证

- Release x64 完整解决方案构建零警告、零错误；Core 单元测试与集成测试全部通过。
- 新增 4 个单元测试：无校验值安装成功、填写校验值但不匹配仍拒绝、清单哈希漂移不再阻断启动校验、无清单时版本回退为 null。
- `Build-EXE.ps1 -Variant Full` 本地端到端构建通过（publish + payload 校验 + ISCC 编译）。

## 已知限制与安全说明

- 升级安装会用随包固定的核心覆盖应用内更新过的核心；如需更新版本，安装后可再次使用应用内核心更新。
- 真实 TUN 未在本机验证；真实安装器安装/升级/卸载、已安装 Windows Service、System Proxy 注册表/WinINet、Explorer 重启、多显示器/DPI/高对比度与睡眠恢复建议在安全环境中手动验收。
- Wi-Fi/SSID 自动切换、ARM64、历史流量分析和更多语言仍不在本版本范围内。
